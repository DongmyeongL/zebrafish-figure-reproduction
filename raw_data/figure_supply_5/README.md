# Figure Supply 5 inputs

This directory contains the complete inputs used by
`figure_code/figure_supply_5.py`.

- `network_diagrams/`: six pre-rendered cell-level network diagrams for the
  original, Null-In, and Null-Out conditions for two example region pairs.
- `null_statistics/`: the saved Base and null-model DCA arrays used to
  recompute panels A and B and their Mann--Whitney U tests.

The inputs were migrated from `final_figure_pack` without modification. Their
SHA-256 hashes are recorded in `source_manifest.csv`.
